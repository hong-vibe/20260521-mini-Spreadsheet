# step4_implementation_plan.md (4단계 구현 계획서 누적 보존본)

본 문서는 사용자의 과제 제출 및 히스토리 증적을 위해 영구 보존되는 4단계 행/열 동적 추가 및 삭제 시스템의 설계서입니다.

---

## 👨‍💻 행/열 추가 및 삭제 상세 설계

### 📌 1. UI/UX 및 제어 버튼 배치
* 상단 제어 바가 복잡해지는 것을 예방하기 위해, 기존의 상단 추가 삭제 제어 버튼 4개를 전면 제거합니다.
* 대신 행/열 머리글(<th>)에 마우스 호버 시, 해당 헤더 내부에 동적으로 미니 `+`, `-` 버튼 콤보가 정교하게 플로팅되어 노출되도록 설계합니다.
* **수직 위아래 정렬 및 시인성 상향**: 미니 버튼을 좌우가 아닌 **위아래(수직 column) 정렬**하여 <th> 셀 내의 마우스 클릭 여백을 극대화하고, `+`와 `-` 기호의 **폰트 크기를 12px로 한 단계 상향 조정**하여 직관적인 시인성을 보강합니다.

### 📌 2. 핵심 알고리즘: 데이터 상태 좌표 실시간 시프트 (Data Shift Engine)
* **행 추가 시 (Shift Down)**: insertAt 기준 하단 행들의 데이터를 1씩 아래로 밀어냄.
* **행 삭제 시 (Shift Up)**: targetRow를 지우고 하단 데이터 좌표를 1씩 위로 당김.
* **열 추가/삭제 시 (Shift Right / Left)**: 알파벳 인덱스 교차 변환기(`getColLetter`, `getColIndex`)를 도입하여 26자 열 한계를 극복하고 동적으로 가로축 데이터를 밀고 당김.

### 📌 3. DOM 동적 조작 및 그리드 재구성
* 테이블 그리드 차원을 `this.maxRows` 및 `this.maxCols`로 전면 상태 변수화합니다.
* 추가/삭제 시 DOM 테이블 격자(`rebuildGrid()`)를 동적으로 재생성하고, 새로 빌드된 모든 `<td>` 셀들에 드래그 범위, 더블클릭 수정, 키보드 네비게이션 이벤트 리스너를 누수 없이 자동 재인입시킵니다.

### 📌 4. [피드백 반영] 5대 프리미엄 UI/UX 폴리싱
1. `Export Spreadsheet` -> `Export` 버튼명 축소.
2. `Sample` 버튼 내 svg 플러스 기호 삭제로 너비 미니멀화.
3. 포커스 셀 인디케이터 너비 130px로 엄격 고정 및 말줄임 처리, 범위 선택 텍스트 간소화.
4. 제목 우측에 `초기화 🔄` 단추 배치. 클릭 시 확인 컨펌 후 9x9 완전 초기 격자로 원복 및 LocalStorage 완전 삭제.
5. 숫자 행 헤더 너비를 45px -> 70px(150% 이상)로 확장하고, th/td 세로 높이를 38px -> 48px로 상향하여 미니 버튼 상하 배치 공간 및 클릭 면적 넉넉히 확보.
